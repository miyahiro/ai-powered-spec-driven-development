# CHG-0008 外部への依存を事前に確かめるフィジビリティ調査を加える

## 目的と範囲

- 目的: 外部クラウドサービス・ミドルウェア・ライブラリに依存する設計を、実装の前に机上調査と小さなプログラムで確かめて、意図どおりに実装できるかを分かるようにする
- 対象: フィジビリティ調査の手順（机上調査、実際のプログラムでの確認）、工程の中での位置付け、調査の記録、関係するエージェント・ガイドの記載
- 対象外: 本番の資格情報を使う確認、外部サービスへの書き込み、調査用のコードを本実装に流用すること
